# Summary

The `.PSS` files are PlayStation Stream files which are a known video format that can be handled by [VGMToolbox](https://github.com/Manicsteiner/VGMToolbox/), `PSS Player`, and [PSS Demux](https://github.com/Joy-Division/tools-zoe/blob/master/pss-demux.c).

Format details can be found [here](https://github.com/Manicsteiner/VGMToolbox/blob/master/format/VGMToolbox/format/SonyPssStream.cs). FFmpeg has some support for it and VLC Media player has some limited support and is able view the video.

These are stored in the `/MOVIE/` folder containing the video content for the bails montages, the professional snowboarder montages, a trailers, and intro videos.

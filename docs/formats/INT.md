# Summary

The `.INT` files are audio files for the in-game music. They're stored in a raw PS2 `PCM16LE` files which are supported by [vgmstream](https://github.com/vgmstream/vgmstream/blob/master/doc/FORMATS.md) and can be converted to `.wav` files. Format specifics can be found [here](https://github.com/vgmstream/vgmstream/blob/e07a4a1f2d32658b8420e046276a7cfc425c9bf2/src/meta/raw_int.c).

They're stored in the `/BGM/` folder.
